# İlk çalıştırma

Önce [native kurulum](SETUP.md) yapılır. Boş kasa paket başlangıç notlarından oluşturulur; dolu kasa migration/kayıt sözleşmesiyle korunur.

`respectedbrain vault list` UUID'yi gösterir. `respectedbrain maps --vault-id <UUID>` haritaları oluşturur. Kişisel bağlamı kasadaki `🔮 850-Companion/Core.md` ve `Kurallar.md` dosyalarına yazın. Başlangıç `{{USER_NAME}}` alanlarını kurulum profili veya kendi notlarınızda kişiselleştirin.

Sağlayıcı CLI'ında oturum açın. `respectedbrain configure --summary-provider <sağlayıcı>` tercihi DataRoot'ta saklanır. [Çoklu AI](MULTI_AI.md) rehberi bağlantıları açıklar. Aktif kod reposu hafıza kasası yerine kullanılmaz.
