# Retired source adapter

The canonical instructions are `src/respectedbrain/resources/instructions/default.md`.
Installed registrations are rendered from the package and the selected vault identity.
Use `respectedbrain repair --vault-id UUID` for managed registrations and
`respectedbrain maps --vault-id UUID` for vault maps. System Python is not required.
Personal instructions belong in `DataRoot/overrides/VaultUUID/instructions/default.md`.
